# Security policy

This is an educational project, not production blockchain software.

Do not use it with real funds, production credentials, or valuable private
keys. Run it only on a trusted local machine. In particular, the tutorial HTTP
API accepts a keystore password to sign transactions and does not provide the
authentication, transport security, rate limiting, or key isolation expected
of a production service.

If you find a vulnerability in the educational code, open a GitHub issue that
describes the behavior without including live credentials or private keys.
